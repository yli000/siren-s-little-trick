## 0. v2 一句话

**挑一首歌，一句一句跟塞壬学着唱；唱完一首，就会有一艘船循着歌声开过来。**

| | v1.1 | v2 |
| --- | --- | --- |
| 画面 | 横屏手绘 | **竖屏像素**（180 逻辑像素宽，整数倍放大） |
| 一局 | 5 句随机旋律 | **一首歌 = 一关**，20 首自由挑，不设解锁 |
| 局中反馈 | 船队前进后退 + 船数 | **只有逐音 Perfect / Great / Good / Miss** |
| 结尾 | 船数 + 结局文案 + 分享卡 | **一艘随机的船开过来，收进图鉴** |
| 判定 | 切音符 + 四维打分 | **逐帧对照目标音**（见 §3） |
| 新增 | — | 练习、图鉴、设置、暂停、English、更新日志 |

### 沿用的 v1 原则

- **P1 敢开口 > 唱得准**：哼唱一等公民；判定宁松勿严。
- **P4 只回应，不评价**：不出现任何诊断话术（"低了""晚了"等）。逐音档位是 v1.1 已批准的例外，只用颜色和单词，不配解释。
- 平台约束全部不变：离线、经典脚本、ES2017 / Chrome 61、无 WASM / Worker、`<audio>` 不用 `data:`、包体建议 ≤ 2MB。

### 废止的 v1 内容

P5「船数就是分数」、船队模拟（fleet）、5 句随机旋律生成（melody）、结局四档文案、分享卡、终局回放录音、前置摄像头、横屏布局与手绘素材。代码在 git 历史里都还在。

## 1. 界面与流程

### 1.1 首页

- 标题有轻微动效（逐字起伏、远处小船、塞壬头发被风吹）。
- 副标题保留「小声哼也行，她听得见」。
- **四个选项：开始 / 练习 / 图鉴 / 设置**。「练习」取代原来的「开嗓」。
- 声音按钮从首页移走，放进设置。

### 1.2 统一的选项样式

全游戏只有 **一种按钮**：同一套底色、描边、按下效果，同一行里的按钮等高。主次只靠位置区分（最常用的放最上 / 最左），不再用金色区分"主按钮"。列表项（歌曲卡、练习卡、设置项）是同一种卡片的不同内容。

### 1.3 开始（选歌）

- 删掉「今晚唱哪首」标题和底部「先开开嗓」卡片。
- **天色改成和首页一样的黄昏**。原型里用深夜没有设计上的理由：深夜在 v2 里代表"一首歌唱到最后"，选歌时还没开始唱，应该和首页同一时刻。
- 20 首歌纵向滚动。每张卡：歌名、难度（1–3 颗）、第一句旋律的走向缩略。
- 唱过的歌，卡片右侧显示 **上次来的那艘船** 的小图；没唱过显示「?」。不显示分数。

### 1.4 唱一首歌

每一句的节奏：

1. **听她唱**：塞壬唱，音块一个个亮起。
2. **倒数**：「到你了」+ 嗒（第一拍）+ 叮（第二拍）；第三拍麦克风打开，第一个音就从这一拍开始。录音期间不播任何提示音（录音不开回声消除，提示音会被录进去）。
3. **你唱**：实时画出你的音高线；每个音唱完后弹出 Perfect / Great / Good / Miss。
4. 下一句。天色随进度从黄昏走到深夜。

顶部：返回（= 暂停）、歌名、句子进度点。不再有"跳过"按钮。

### 1.5 结尾

船笛 → 黑场 → 海面上一艘船从地平线开近 → 揭晓：船名丝带、稀有度星级、「新发现!」或「第 N 次来」、介绍卡逐字出现 → 「再唱一遍 / 换一首 / 图鉴」。
点屏幕可以跳过开船和逐字。没有"有船来了"之类的字幕，船笛就够了。

抽船规则：按稀有度加权（普通 50 / 稀有 30 / 史诗 15 / 传说 5），没见过的船权重 ×3。**与唱得好坏无关**。

### 1.6 暂停

- 唱歌和练习中，左上角返回按钮 = 暂停。
- 暂停弹层：**继续 / 重新开始 / 退出**。
- 切到后台（`visibilitychange`）自动暂停。
- 暂停时立刻停掉所有声音和麦克风采集；继续时 **从当前这一句的"听她唱"重新开始**（一句只有几秒，从中间接上反而对不上节拍）。

### 1.7 图鉴

21 艘船三列网格；没来过的显示剪影；点开看大图、编号、稀有度、来过几次和介绍。

### 1.8 设置

| 项 | 说明 |
| --- | --- |
| 声音 | 开 / 关（全部声音） |
| 语言 | 中文 / English（默认跟随系统，选过之后记住） |
| 更新日志 | 见 §6 |
| 关于 | 作者、版本、字体授权，见 §7 |
| 清除进度 | 清空图鉴、唱过的歌、练习记录和音区；二次确认 |

**还需要什么？** 我认为这五项就够了。考虑过但不加的：画质 / 帧率（像素画没有负担）、震动（容器不支持传感器类能力）、账号 / 云同步（PRD 非目标）、麦克风选择（`enumerateDevices` 被容器禁用）。

### 1.9 删除的演示专用设计

「演示模式 / 自动跟唱」字样和模拟出来的歌声与档位、局中「跳过」按钮、预置的图鉴数据、切换塞壬版本的按钮、常驻的测试钩子（改为只在地址带 `?dev=1` 时开启）。

## 2. 修复：离开后声音还在响

**现象**：从「开嗓」退出后，塞壬还在继续唱。

**原因**：原型在一句开始时就把整句的音一次性排进音频时间线，退出只切了画面，没有取消已经排好的音。选歌那边恰好没暴露是因为一句较短、退出时多半已经唱完。

**v2 做法**：所有发声都走 `Siren.Audio`，它登记每一个排程中的音；**离开任何一个唱歌界面、暂停、切后台** 都调用 `Audio.stopPlayback()` 并释放麦克风。测试里加一条：退出后 100ms 内活跃声部数必须为 0。

## 3. 判定（取代切音符 + 四维打分）

### 3.1 为什么换

v1 的流程是「逐帧测音高 → 切成音符 → 和目标配对 → 四维打分」。合成人声实测的问题：

| 情况 | v1 结果 | 原因 |
| --- | --- | --- |
| 音和音之间滑过去 | 97 → 57 | 过渡段被切出多余的音，走向和完整度一起扣 |
| 颤音较大（±60 音分） | 0 分 | 每个音都被判"不稳"，切不出音 |
| 半音（如 mi→fa→mi） | 唱得再准也只有 85 | 走向分里 `Math.round(±0.5)` 正负不对称 |
| 整体低 1 个半音、晚 150ms | 总分 98，屏幕上却是 Great/Great/Good/Great | 逐音档位没做移调和延迟补偿 |

K 歌游戏（SingStar 的开源复刻 UltraStar Deluxe）的做法是：**不切音符，每一拍拿玩家的音高去对这一拍该唱的目标音**，折八度后差距在容差内就算唱中。我们的场景知道每个音该什么时候唱（有倒数和音块），正好适用。

### 3.2 v2 流程（`core/judge.js`）

1. **测音高**：沿用 `pitch.js`（YIN，50ms 一帧，主线程）。
2. **有效帧**：有音高、置信度够、电平高于静音门槛（底噪 × 1.8，且不高于本句峰值的 20%）。
3. **估整体偏移**（每句一次）：
   - 时间偏移 L：在 −150 ～ +300ms 里以 25ms 为步长穷举；
   - 调偏移 K：每个候选 L 下，取"落在目标音里的帧"与目标音之差，折八度后的中位数；
   - 选让"唱中帧数"最多的 (L, K)。
4. **逐帧打分**：一帧和目标音（加上 K）的差，折八度后 ≤ 50 音分记 1 分，≥ 150 音分记 0 分，中间按比例。
5. **逐音档位**：一个音的时间窗（平移 L，前 60ms 不算，给起音和滑音留余量）里，所有帧（包括没出声的帧）的平均分 a：

   | a | 档位 |
   | --- | --- |
   | ≥ 0.75 | Perfect |
   | ≥ 0.50 | Great |
   | ≥ 0.25 | Good |
   | 其余 | Miss |

6. **一句的分数** = 各音 a 的平均 × 100，只在内部用（练习的自适应）。**档位和分数同源**，不会出现"全是 Perfect 但分数很低"。
7. **实时**：每个音在它结束后 300ms 判定并显示（等足够的帧来估偏移）。

### 3.3 调的规则（解决 PRD 与代码的冲突）

- **唱歌：调完全不限**。用什么调唱都行，只看音和音之间的关系对不对。这就是 PRD P2「整体移调不扣分」的本意，v1 代码里 ±2 半音的上限取消。
- **练习第 1 组「找到第一个音」：调要对**（只允许差整八度），因为这一组练的就是对准她给的音。

### 3.4 前后对比（目标）

| 情况 | v1 | v2 目标 |
| --- | --- | --- |
| 唱得干净 | 97–98 | Perfect 为主 |
| 滑音 | 57 | 与干净演唱差距 ≤ 1 档 |
| 颤音 ±60 音分 | 0 | Great 以上 |
| 半音句 | 85 封顶 | 与其他句无差别 |
| 整体低 1 个半音、晚 150ms | 屏幕 Great / Good | Perfect 为主 |

这些都写进自动测试（合成人声，见 `tools/test-judge.mjs`）。**阈值以真机真人测试为准**，上线前必须找 3–5 人在手机上试唱并留存录音。

### 3.5 麦克风被拒

保留 v1 的兜底：**点按节奏**。轮到你时按着节拍点麦克风按钮，每点一下对一个音，只看时间（误差 ≤ 100ms Perfect、≤ 180ms Great、≤ 300ms Good）。设置里不需要开关，拒绝授权时自动进入，并提示一次"允许麦克风就能唱了"。

## 4. 练习（取代开嗓）

**设计依据**（详见对话记录中的调研）：

- 真跑调的人约 10–16%，问题多在"把听到的音变成嗓子的动作"，而不是耳朵；典型错误是整句偏高 / 偏低、音程唱小、往自己舒服的音高漂。
- 目标音在不舒服的音区会放大这些错误；按各人舒服的音高出题能消除整体偏移。
- 声乐课的顺序：单音 → 级进 → 跳进 → 音阶 / 琶音。

**五组练习，每组对准一个"为什么过不去"**：

| # | 名称 | 练什么 | 内容 |
| --- | --- | --- | --- |
| 1 | 找到第一个音 | 整句偏高 / 偏低 | 先随便哼一个舒服的音（测出你的舒服音高）；她唱一个长音，你哼同一个，3 个音。**她不陪唱** |
| 2 | 一步一步走 | 级进 | do-re-do → do-re-mi-re-do → do-re-mi-fa-sol-fa-mi-re-do |
| 3 | 跳过去 | 音程唱小 | do-mi-do → do-sol-do → do-高do-do |
| 4 | 爬梯子 | 音区 | do-re-mi-re-do 每遍升半音，唱不上去就往下走，记下最高和最低 |
| 5 | 记更长 | 记忆 | 3 音 → 5 音 → 7 音 |

- 每组 3 步，30–60 秒。一步的分数 ≥ 60 进入下一步；连续两次 < 40 也放行（练习不卡人）。
- 第 1、4 组测出的 **舒服音高与音区** 存下来，**唱歌时把每首歌移到你的音区里**（最多移 ±6 半音）。没做过练习就用默认调。
- 完成的组在列表上打勾。**不做成就系统，塞壬的样子不变**——她是老师，不是玩家。
- 练习用白天的天色，不出船。

## 附：游戏视角审查（2026-10-13）与处理

由一个独立 agent 实际试玩原型并通读本文后给出。**下列处理方式优先于正文**，正文冲突处以此为准。

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 录音时档位音效、海浪还在响，会被录进去；底噪找不到安静的时机测 | **采纳**。倒数开始时海浪淡到 0；录音期间档位只变色不出声；一首歌里麦克风一直开着，底噪在每首开场的标题卡和每句之后的空档里测 |
| 2 | 练习"≥60 进下一步"会卡住分数在 40–59 的人 | **采纳**。每步最多 3 遍，第 3 遍后直接放行；重来只说「再来一遍」 |
| 3 | 没定什么时候要麦克风权限 | **采纳**。第一次点歌或练习时先出一张卡（「她要听你唱」「声音只在你的手机里处理，不会上传」+「好」），拿到结果前游戏停在这张卡上 |
| 4 | 新手不知道什么时候开口；倒数和旋律不在同一拍 | **采纳**。第一次玩先「哼一声试试」（3 秒，看到音高线跟着自己动）；第一句给「她先唱」「轮到你」两条提示；倒数改为三格：嗒、嗒、麦克风图标，**按这首歌的拍速**，麦克风那一格正好是第一个音 |
| 5 | "她听得见"的反馈太弱 | **采纳**。目标音块保持亮描边，唱进容差时当前块亮起；音高线 2px 加亮色线头；麦克风圆盘外圈随音量起伏 |
| 6 | 原始音高线 + 不限调，画面等于在说"你低了" | **采纳**。调偏移 K、时间偏移 L 从上一句的值起步、边唱边更新；音高线先按 K 平移再画；档位一出不再改，一句的分数取已显示档位的平均 |
| 7 | 不出声得到一排 Miss 和一声低音 | **采纳**。一句几乎没声音时不出档位，她再唱一遍（最多两次，之后静静进入下一句）；电平接近 0 时才提示「没听到声音，靠近一点麦克风」；Miss 去掉音效 |
| 8 | 「连对 N」是在打分 | **采纳**，删掉。改为她的光晕和爱心随"出声"增加 |
| 9 | 长期动力不足：集齐 21 艘中位数要 65 首 | **部分采纳**。每首歌有一艘「常客」船（权重 ×3，选歌卡上显示它的剪影 / 彩色）；保底：连续 2 艘重复后下一艘必是新船；首页远处的小船换成最近来过的 3 艘。来访满 N 次加文案暂不做 |
| 10 | 关掉全部声音就听不到她唱 | **采纳**。设置项改为「音效与海浪」，她的歌声不受影响 |
| 11 | 练习的好处看不见，练完回不到唱歌 | **采纳**。每组练完一句话 +「再练一组 / 去唱歌」；第 1、4 组后提示「她记住你的调了」，选歌页顶部显示「按你的调」；没练过的人从唱歌时估出的 K 被动学习偏好调 |
| 12 | 安卓返回键 / 侧滑可能直接关掉小工具 | **采纳，需真机验证**。用 `history.pushState` + `popstate` 接住返回，按游戏内返回处理（唱歌中 = 暂停） |
| 13 | 档位字会叠在一起 | **采纳**。档位颜色直接填进音块，块上方只留一个短标签，新的替掉旧的 |
| 14 | 20 首不好挑 | **采纳**。第一次只高亮「从这首开始」（小星星）；列表顶部「随便来一首」；记住上次唱的那首；拖动有惯性 |
| 15 | 结尾边角：存档太晚、跳过后误触、图鉴返回位置 | **采纳**。唱完那一刻就抽船存档；按钮出现后 0.3s 内不响应；从结尾进图鉴，返回回到结尾 |
| 16 | 同一个返回箭头两种意思 | **采纳**。唱歌 / 练习里换成暂停图标 |
| 17 | 拒绝麦克风后没有回头路 | **采纳**。设置里加「麦克风：未允许（点这里再试）」 |
| 18 | 爬梯子规则不清，"唱不上去为止"像考试 | **采纳**。固定 5 遍：升 1、3、5 个半音，再降 2、4 个；往上第一次唱不好就转去往下；不给玩家看任何音域数字 |
| 19 | 更新日志「都不再算错」像在说她以前挑错 | **采纳**。改为「颤音、滑音、用自己的调唱，她都听得懂了」/ "She follows vibrato, slides and your own key now"；§6 同步修改 |
