## 2. 麦克风

- **只在唱的时候开**：暂停、离开唱歌界面、切后台都关。手机上「正在使用麦克风」的提示是系统或浏览器弹的，每开一次弹一次；这样它如实告诉玩家现在有没有在听。
- **第一次唱**：点「先试一句」时直接要麦克风，浏览器弹它自己的授权框，游戏不再先弹一张说明卡。
- **被拒绝了**：弹一张卡「麦克风好像没打开。」，按钮「先这样 / 打开麦克风」。「打开麦克风」会再要一次，浏览器再弹它自己的授权框。浏览器记住了拒绝、不再弹框时，卡上才补一句去哪里打开（地址栏左边的图标 → 网站设置 → 麦克风 → 允许）。唱歌时点带斜杠的麦克风也会再要一次。
- **设置里的麦克风**：网页收不回已经给的权限，所以「已授权」只显示状态。「未授权」点一下会打开一下麦克风再马上关掉，让浏览器弹出自己的授权框；被浏览器拒绝过（它不会再弹）才显示上面的打开步骤。

## 3. 「怎么玩」教程

第一次唱之前（从选歌或练习进来都一样）。文案由克克定稿（2026-10-14）：

1. 卡片「怎么玩」：塞壬唱一句，你跟一句。→「先试一句」（这一下要麦克风，浏览器弹授权框）
2. 框住音块：先听塞壬唱。音块越高，音越高。→ 塞壬唱
3. 框住音块和麦克风：开口唱吧 :)（只讲第一次；没有麦克风时换成「麦克风好像没打开。」+「打开麦克风」）
4. 倒数「嘀、嘀、叮」开始就显示：红线是你的声音，贴着音块唱。唱过、还在等判定的音块先变浅色。
5. 没出声：好像没听到你的声音。（最多两次）
6. 收尾按这一遍的结果说：大部分对上了「接下来唱一整首歌啦。」；一半以上是 Miss「再听一遍？」（「再试一次」放主位）；没有麦克风「麦克风好像没打开。」+「打开麦克风」。→「再试一次 / 开始唱」，开始唱就直接进玩家点的那首歌。

教程这一句放慢到 80 拍，不记进度、不抽船。

### 试玩

由两个没看过文档的 agent 当第一次玩的人，用无头浏览器从头玩（看截图、听声音日志、模拟唱对 / 唱错 / 不出声 / 拒绝麦克风 / 英文）。第一轮之后改了上面大部分；第二轮能只靠教程看懂并唱完整首。

没采纳的意见和原因：

| 意见 | 原因 |
| --- | --- |
| 没麦克风时暂停游戏 / 只听她唱 | 定了：没麦克风就当 Miss，不做第二种模式 |
| 要麦克风之前先预告一句 | 定了：直接弹浏览器的授权框 |
| 告诉玩家「唱得越像，来的船越稀有」 | 不是事实：来哪艘船和唱得好坏无关（后来连稀有度也去掉了，见第 6 节） |
| 「红线在上面是唱高了」 | PRD P4：不出现高了 / 低了之类的诊断 |
| 唱对时夸一句、结尾给分数汇总 | 只回应，不评价 |

两个试玩的人都**自己推断**出「唱得越像船越稀有」。原因是船的介绍还留着早期「按表现出船」方案的写法（如瓶中船「只会漂向唱得和塞壬一模一样的人」）。处理见第 6 节。

## 4. 声音

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 锁屏回来没声音，要刷新 | iPhone（Safari 和 iOS 上的 Chrome 都是 WebKit）锁屏、来电后 AudioContext 停在非标准的 `interrupted` 状态，原来只在 `suspended` 时恢复 | 只要不在 running 就恢复；点了一下 0.6 秒后还起不来，下一次点击整个重建 |
| 切回来没声音 | 切后台时挂起，有的容器回来不发 `visibilitychange` | 点击时只要页面可见就解除挂起；`pageshow`、`focus` 也试着恢复 |
| 每句第一个音晚 | 每一句开头都重算 1.6 秒的混响（约 15 万个采样）、每个音新建音色波形 | 都只生成一次；切尾音改为把湿声关到 0，下一个音开始时再打开 |
| 按键声慢半拍 | 手指抬起才响 | 按下就响（能拖动的列表里还是抬起才响，免得滑动时也响） |

## 6. 船：没有等级，机会一样

定了：**来哪艘船和唱得好坏、唱哪首歌都无关，21 艘船的机会一样。**

- 去掉稀有度（普通 / 稀有 / 史诗 / 传说）、星星和按等级分的颜色。所有船揭晓时都是金色名牌，图鉴格子都是同一种边框。
- 去掉每首歌的「常客船」。选歌卡右边改成这首歌上次来的那艘船，没唱过是问号。
- 为了让玩家把每艘船的介绍都看到：还有没见过的船时，只在没见过的里面抽，唱满 21 首就见齐。见齐之后在全部里面抽，只是不和上一艘相同。
- 船的介绍：去掉所有暗示条件的写法（走音、节奏对上、好歌、唱得一模一样、每周二、满月前后、夏天清晨），顺便改了作业纸船、瓶中船里不通顺的地方。共改 9 艘：作业纸船、潜水艇、龙舟、幽灵船、宝船、瓶中船、荷叶船、邮船、月亮船。
- 文字换行：最后一行只剩一个词或两三个字时，从上一行借一个下来。
